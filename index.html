设置

把原始内容放进 State

把工单、邮件、用户消息的原文粘进 State 输入框——纯文本即可； 结构化数据可切换「JSON 结构化对象」。内容越贴近真实业务，判断越准。

2

选任务，填表单，执行

四张任务卡选一个（分类 / 打分 / 是非 / 批量），填好 Key 与判断指令， 点击 ▶ 执行推理（或 Ctrl+Enter）。 一题只判断一件事，复杂情况拆成多题。
